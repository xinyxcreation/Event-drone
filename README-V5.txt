V5
- Suppression du texte « Actions : OK = fermer · Annuler = gérer ce type ».
- Le détail n'utilise plus confirm() avec OK/Annuler.
- Le détail permet IGNORER / RETABLIR un type via une saisie explicite, ou vide pour fermer.
- La V4 n'avait aucun mécanisme d'import/capture d'écran : une capture d'écran n'était donc pas une donnée que l'application pouvait accepter. L'interface reste basée sur les événements JSON.

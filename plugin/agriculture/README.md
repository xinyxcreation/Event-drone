# 🌾 Event-drone — Agriculture V7

Module Agriculture pour Event-drone.

## Important

Le module charge automatiquement `agriculture.css` depuis `agriculture.js`.
Il n'est donc **pas nécessaire de modifier `index.html`** ni d'ajouter un `<link>`.

Le module ne modifie pas les dimensions de l'application : il utilise simplement la largeur disponible de `main`.

## Affichage

- une seule introduction en haut ;
- aucune barre calendrier globale ;
- calendrier `J F M A M J J A S O N D` dans chaque carte ;
- mois actuel entouré en rouge ;
- jaune = prospection thermique ;
- vert = récolte/fauche ;
- liseret complet de la carte selon la période actuelle ;
- clic sur la carte pour afficher les détails ;
- aucun niveau en étoiles.
